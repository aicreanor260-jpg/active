# Глава 8 — комплект для генерации HTML-презентации

Учебные материалы, визуальный стиль, примеры и локальные ресурсы для Gemini или передачи в Google Stitch.

## Для Stitch: всё уже переведено в Markdown

Используйте **[stitch/STITCH-ALL.md](stitch/STITCH-ALL.md)**: задание, дизайн, оба PDF, все 29 слайдов PPTX и текстовые описания иллюстраций в одном файле. Скачайте файл и передайте его содержимое, вместо извлечения страницы GitHub.

Есть [TXT-копия](stitch/STITCH-ALL.txt), [части для вставки в чат](stitch/parts) и [инструкция](stitch/START-HERE.md). PDF/PPTX для этого варианта не нужны. Отдельно приложите [картинку стиля](stitch/style-reference.png).

## Начало работы

1. Прочитайте [DESIGN.md](DESIGN.md): палитра, типографика, композиции, адаптивность, навигация и анимации.
2. Скопируйте [PROMPT.txt](PROMPT.txt) в запрос генератору.
3. Передайте два PDF из `sources`, `assets/style-reference.png` и текстовые примеры `upload/*-reference.txt`. PPTX — дополнительный исходник; `upload/lecture-text.txt` — вспомогательная выгрузка текста PDF.
4. Передайте нужные ресурсы из `assets` вместе с `assets/image-index.json`. Шрифты находятся в `fonts`.
5. Сохраните полученный HTML как `index.html` в корне скачанного комплекта и откройте в браузере.

Репозиторий содержит исходные материалы и задание, а не готовую новую презентацию.

## Передача в Google Stitch

Скачайте репозиторий через **Code → Download ZIP** и распакуйте. Передайте `DESIGN.md`, визуальный референс и задание через поддерживаемые интерфейсом способы загрузки. Если тип файла не принимается, вставьте содержимое текстового файла в запрос. Доступность импорта приватного GitHub-репозитория зависит от возможностей и подключения аккаунта в используемом интерфейсе; одна ссылка не гарантирует доступ к файлам.

Текст для начала работы:

> Создай интерфейс HTML-презентации «Глава 8. Транспортный уровень» по приложенному DESIGN.md и визуальному референсу. Полное задание находится в PROMPT.txt, учебное содержание — в источниках. Обязательны адаптивная верстка, фиксированные стрелки справа внизу, вертикальная прокрутка переполненного слайда и плавные анимации. Используй реальные ресурсы комплекта. Если исходник недоступен, явно назови его, не выдумывай содержание.

## Состав

| Путь | Содержание |
| --- | --- |
| `DESIGN.md` | Правила оформления и поведения |
| `PROMPT.txt` | Полное задание на генерацию |
| `sources/` | Два PDF и PPTX |
| `examples/` | Оригинальные HTML-примеры и SVG |
| `upload/` | Текстовые копии примеров и выгрузка лекций |
| `assets/` | Визуальный референс, извлечённые ресурсы и их индекс |
| `fonts/` | Oswald, Inter, STIX Two Math |

Текстовые копии HTML содержат маркеры вместо тяжёлых base64-ресурсов и предназначены для чтения, а не запуска. Оригиналы сохранены в `examples`. Извлечённые ресурсы могут быть фрагментами схем; сверяйтесь с PDF/PPTX.

Материалы собраны из предоставленных пользователем файлов. Открытая лицензия на весь комплект не заявляется.
