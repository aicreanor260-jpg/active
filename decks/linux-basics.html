Что такое дистрибутив

Одна идея — разные возможности

01Ядро
Управляет процессором, памятью, устройствами и файловыми системами. Одно и то же у всех дистрибутивов, отличается только версией.
02Системные инструменты
Оболочка, утилиты работы с файлами, менеджер пакетов, система инициализации. То, с чем работает человек в терминале.
03Библиотеки
Готовый код, которым пользуются программы: вывод на экран, работа с сетью, шифрование. Ставятся вместе с программами.
04Приложения
Браузер, редактор, офис, средства разработки. Набор зависит от того, для чего собран дистрибутив.
i

Сменить дистрибутив не значит выучить другую систему: ядро, дерево каталогов и команды остаются теми же. Меняются набор программ, оформление и менеджер пакетов.

Terminal

Зачем нужен терминал

Одна строка вместо десятка щелчков мышью

Терминал — окно, в котором работает командная оболочка. Она читает строку, запускает программу и показывает её вывод. Всё, что делается мышью в графическом интерфейсе, здесь делается командой — и наоборот, многое доступно только так.
Приглашение командной строки
kali@kali:~$
kali — имя пользователя, после @ — имя компьютера, после двоеточия — текущий каталог (~ означает домашний), символ $ — обычный пользователь, # — суперпользователь root.
Структура:команда -флаги аргументы
Пример:ls -l /etc
kali@kali: ~
kali@kali:~$ whoami
kali
kali@kali:~$ hostname
kali
kali@kali:~$ ls -l /etc/hosts
-rw-r--r-- 1 root root 221 Oct 10 12:30 hosts
i

Команда — что выполнить, флаги — как именно, аргументы — над чем работать. Короткие флаги объединяются: -l -h и -lh — одно и то же.

Файловая система

Одно дерево от корня, а не отдельные диски с буквами

/ корень дерева
bin исполняемые файлы команд
etc настройки системы
home домашние каталоги пользователей
kali
Desktop
Documents
Downloads
report.txt
var журналы и изменяемые данные
usr программы и их данные
tmp временные файлы
Путь: /home/kali
01Абсолютный путь
Начинается с косой черты и отсчитывается от корня: /home/kali/Documents. Работает откуда угодно.
02Относительный путь
Отсчитывается от текущего каталога: Documents/notes.txt. Короче, но зависит от того, где вы находитесь.
03Особые обозначения
. — текущий каталог, .. — родительский, ~ — домашний каталог пользователя, / — корень.
i

Регистр букв различается: Report.txt и report.txt — два разных файла. Имена, начинающиеся с точки, считаются скрытыми.

Основные команды

Где я нахожусь, что здесь лежит и как перейти в другой каталог

01pwd
Печатает абсолютный путь текущего каталога. Первая команда, когда непонятно, где вы оказались.
02ls
Показывает содержимое каталога. Без аргументов — текущего, с аргументом — указанного.
03cd
Переходит в другой каталог. Без аргументов возвращает в домашний.
kali@kali: ~
kali@kali:~$ pwd
/home/kali
kali@kali:~$ ls
DesktopDocumentsDownloadsPicturesTemplatesreport.txt
kali@kali:~$ cd Downloads
kali@kali:~/Downloads$ pwd
/home/kali/Downloads
kali@kali:~/Downloads$ cd ..
/home
kali
Desktop
Documents
Downloads
i

Рамкой отмечен текущий каталог: он меняется вместе с командой cd, а pwd подтверждает новое положение.

  • 1
    pwd — узнать, где вы находитесь сейчас.
  • 2
    ls — посмотреть, что лежит рядом.
  • 3
    cd имя — перейти внутрь, cd .. — вернуться на уровень выше.

Команда ls

Один и тот же каталог выглядит по-разному в зависимости от флагов

01ls -l
Подробный список: права, владелец, размер, дата, имя — по одной строке на объект.
02ls -a
Показывает скрытые файлы, чьи имена начинаются с точки, вместе с обычными.
03ls -lh
То же, что -l, но размеры в понятном виде: 4,0K вместо 4096.
kali@kali: ~
kali@kali:~$ ls -a
....bashrcDocumentsDownloadsreport.txt
kali@kali:~$ ls -lh
итого 12K drwxr-xr-x 2 kali kali 4,0K Oct 10 12:30 Documents drwxr-xr-x 2 kali kali 4,0K Oct 10 12:30 Downloads -rw-r--r-- 1 kali kali 1,2K Oct 10 12:30 report.txt

Разбор строки ls -l

- rw-r--r-- 1 kali kali 0 Oct 10 12:30 test.txt
-тип объекта — «-» обычный файл, «d» каталог, «l» символьная ссылка.
rw-r--r--права доступа — Три тройки: владелец, группа, остальные. r — чтение, w — запись, x — исполнение.
1число жёстких ссылок — Сколько имён в файловой системе указывает на эти же данные.
kaliвладелец — Пользователь, которому принадлежит файл.
kaliгруппа — Группа, которой принадлежит файл.
0размер — Размер в байтах. С флагом -h — в килобайтах и мегабайтах.
Oct 10 12:30время изменения — Когда содержимое файла менялось в последний раз.
test.txtимя — Имя файла или каталога.

Команда touch

Создание пустых файлов и изменение времени доступа

Синтаксис:touch [флаги] имя_файла
Пример:touch test.txt
kali@kali: ~
kali@kali:~$ ls
DocumentsDownloadsreport.txt
kali@kali:~$ touch test.txt
kali@kali:~$ ls
DocumentsDownloadsreport.txttest.txt
kali@kali:~$ touch -t 202410101230 test.txt
kali@kali:~$ ls -l test.txt
-rw-r--r-- 1 kali kali 0 Oct 10 12:30 test.txt
i

Файл test.txt появляется в выводе ls сразу после выполнения команды. Флаг -t задаёт время в формате ГГГГММДДччмм — в подробном выводе видно новую дату.

01touch test.txt
Создаёт пустой файл. Если файл уже есть — содержимое не трогает.
02touch a.txt b.txt c.txt
Создаёт сразу несколько файлов одной командой.
03touch -t 202410101230 f
Задаёт файлу указанное время: год, месяц, день, часы, минуты.
04touch report.txt
Для существующего файла обновляет время последнего изменения на текущее.

Каталоги: mkdir и rmdir

Создание и удаление каталогов

Синтаксис:mkdir [-p] имя_каталога
Пример:mkdir -p lab2/src/bin
kali@kali: ~
kali@kali:~$ mkdir lab1
kali@kali:~$ ls
DocumentsDownloadslab1report.txt
kali@kali:~$ mkdir -p lab2/src/bin
kali@kali:~$ ls lab2/src
bin
kali@kali:~$ rmdir lab1
i

Без флага -p команда откажется создавать lab2/src/bin, пока нет промежуточных каталогов. С флагом создаётся вся цепочка сразу.

01mkdir
Создаёт каталог в текущем или указанном месте. Несколько имён — несколько каталогов.
02mkdir -p
Создаёт всю цепочку вложенных каталогов и не ругается, если каталог уже существует.
03rmdir
Удаляет только пустой каталог. Если внутри что-то есть — откажется работать.

Копирование: cp и mv

Копировать, переместить, переименовать

Синтаксис:cp [-r] источник назначение
Пример:cp report.txt backup.txt
kali@kali: ~
kali@kali:~$ ls
Documentsreport.txt
kali@kali:~$ cp report.txt backup.txt
kali@kali:~$ ls
Documentsbackup.txtplan.mdreport.txt
kali@kali:~$ mv notes.txt plan.md
kali@kali:~$ mv plan.md Documents/
i

Переименования как отдельной команды в Linux нет: mv старое_имя новое_имя перемещает файл внутри того же каталога, то есть меняет ему имя.

01cp файл копия
Копирует файл. Исходный остаётся на месте, появляется второй.
02cp -r каталог копия
Копирует каталог со всем содержимым. Без -r каталог не копируется.
03mv файл каталог/
Перемещает файл. В исходном месте он исчезает.
04mv старое новое
Если назначение не каталог, файл получает новое имя.
Terminal

Удаление: rm

Команда без корзины и без вопросов

Синтаксис:rm [-r] [-f] имя
Пример:rm -r lab2
kali@kali: ~
kali@kali:~$ ls
Documentsbackup.txtlab2report.txt
kali@kali:~$ rm backup.txt
kali@kali:~$ rm lab2
rm: невозможно удалить 'lab2': Это каталог
kali@kali:~$ rm -r lab2
kali@kali:~$ ls
Documentsreport.txt
!Что важно помнить
Удалённое командой rm не попадает в корзину и не восстанавливается обычными средствами. Особенно опасны шаблоны: rm -rf * в неверном каталоге уносит всё его содержимое. Перед удалением по шаблону выполните с ним же ls и посмотрите, что попадёт под команду.
01rm файл
Удаляет файл. Каталог так удалить нельзя — команда откажется.
02rm -r каталог
Удаляет каталог вместе со всем содержимым, рекурсивно.
03rm -f файл
Не задаёт вопросов и не жалуется на отсутствующие файлы. Сочетание -rf — самое опасное в системе.
04rm -i файл
Наоборот, спрашивает подтверждение на каждый файл.

Просмотр файлов

Четыре способа заглянуть внутрь, не открывая редактор

kali@kali: ~
kali@kali:~$ cat report.txt
Отчёт по лабораторной работе Дата: 10 октября Исполнитель: kali
kali@kali:~$ head -2 report.txt
Отчёт по лабораторной работе Дата: 10 октября
kali@kali:~$ tail -1 report.txt
Исполнитель: kali
kali@kali:~$ wc -l report.txt
3 report.txt
i

Для больших файлов cat неудобен: содержимое пролетает мимо экрана. Тогда используют less — стрелки листают, / ищет, q выходит.

01cat
Выводит файл целиком. Подходит для коротких файлов и конфигураций.
02less
Постраничный просмотр с поиском. Не загружает файл в память целиком.
03head -n
Первые строки файла, по умолчанию десять.
04tail -n
Последние строки. С флагом -f показывает новые строки по мере появления.

Права доступа

Кто может читать, изменять и запускать файл

Первые десять символов вывода ls -l описывают тип объекта и три набора прав: для владельца, для его группы и для всех остальных. - rw- r-- r--

Владелец

0

Группа

0

Остальные

0
Число для chmod 644 -rw-r--r--
i

Нажимайте буквы: r даёт 4, w — 2, x — 1. Внутри тройки веса складываются, и три получившиеся цифры образуют число для chmod.

Синтаксис:chmod права имя
Пример:chmod 755 script.sh
01chmod 644 файл
Владелец читает и пишет, остальные только читают. Обычный файл с данными.
02chmod 755 файл
Плюс право запуска для всех. Так ставят права скриптам и программам.
03chmod +x файл
Символьная форма: добавить право запуска, не трогая остальное.
04chown пользователь:группа
Меняет владельца и группу файла. Требует прав суперпользователя.

Справка: man и --help

Как отвечать на свои вопросы без поиска в интернете

kali@kali: ~
kali@kali:~$ man ls
LS(1) User Commands LS(1) NAME ls - list directory contents SYNOPSIS ls [OPTION]... [FILE]...
kali@kali:~$ mkdir --help
Usage: mkdir [OPTION]... DIRECTORY... -p, --parents no error if existing, make parent directories as needed -v, --verbose print a message for each created directory
i

В man листают стрелками, ищут по /слово, выходят клавишей q. Раздел в скобках после имени — LS(1) — означает: пользовательские команды.

01man команда
Полное руководство: назначение, синтаксис, все флаги, примеры, связанные команды.
02команда --help
Короткая справка прямо в терминале. Быстрее, когда нужно вспомнить один флаг.
03man -k слово
Поиск по описаниям всех руководств, когда неизвестно имя нужной команды.
04whatis команда
Одна строка: что эта команда делает.
i

Разделы руководств: 1 — команды, 5 — форматы файлов, 8 — команды администратора. Отсюда запись man 5 passwd — про формат файла, а не про команду.
