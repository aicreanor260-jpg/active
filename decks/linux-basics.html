Файловая система Linux

Три уровня, которые обеспечивают работу с файлами: от приложений до диска

01Пользовательские приложения открыть | читать | записать | закрыть
02VFS — виртуальная файловая система общий интерфейс
03Конкретные файловые системы ext4, XFS, Btrfs, FAT32, NTFS
04Дисковое хранилище блоки, узлы, физическая память
01Логическая файловая система
Выступает в качестве интерфейса между приложениями и файловой системой. Выполняет ключевые операции: открытие, чтение, запись и закрытие. Обеспечивает проверку безопасности, в том числе разрешений и контроля доступа к файлам.
02Виртуальная файловая система (VFS)
Предоставляет общий интерфейс для различных файловых систем (ext4, XFS, FAT32, NTFS). Позволяет Linux использовать несколько типов файловых систем одновременно и скрывает внутренние сложности каждой из них.
03Физическая файловая система
Непосредственно взаимодействует с аппаратным обеспечением и дисковым хранилищем. Управляет блоками данных, узлами и распределением физической памяти. Отвечает за запись данных на диск и их извлечение.

Terminal

Зачем нужен терминал

Одна строка вместо десятка щелчков мышью

Терминал — окно, в котором работает командная оболочка. Она интерпретирует и выполняет ваши команды, а затем показывает результат. Примеры оболочек: bash, zsh, sh.
Приглашение командной строки
kali@kali:~$
kali — имя пользователя, после @ — имя компьютера, после двоеточия — текущий каталог (~ означает домашний), символ $ — обычный пользователь, # — суперпользователь root.
Структура:команда -флаги аргументы
Пример:ls -l /etc
kali@kali: ~
kali@kali:~$ whoami
kali
kali@kali:~$ pwd
/home/kali
kali@kali:~$ ls -l /etc/hosts
-rw-r--r-- 1 root root 221 Oct 10 12:30 hosts
i

Команда — что выполнить, флаги — как именно, аргументы — над чем работать. Короткие флаги объединяются: -l -h и -lh — одно и то же.

Работа с файлами и каталогами в Linux

01pwd
(вывести рабочий каталог)
Команда pwd показывает текущее местоположение в системе. Она сообщает, в какой папке вы находитесь.
02ls
(вывести список файлов и каталогов)
Команда ls используется для вывода списка файлов и каталогов в текущем каталоге. Она позволяет получить общее представление о содержимом папки.
03cd
(смена каталога)
Команда cd используется для перемещения между папками. Вы можете указать, в какую именно папку хотите перейти, или использовать ярлыки для навигации.
kali@kali: ~
kali@kali:~$ pwd
/home/kali/Templates
kali@kali:~$ ls
DesktopDocumentsDownloadsMusicPicturesTemplatesVideosbin
i

Текущий каталог — /home/kali/Templates. Командой ls отображаются все файлы и папки, находящиеся в текущей папке.

kali@kali:~$ cd Downloads

    Используйте команду pwd, чтобы убедиться, что вы находитесь в нужной папке.

    Выведите список файлов и каталогов, чтобы увидеть содержимое новой папки.

Права доступа к файлам

Кто и какие действия может выполнять с файлами и каталогами в системе

Три основных типа разрешений

01Чтение (r)
Просмотр содержимого файла или списка файлов в каталоге. r = read
02Запись (w)
Изменение содержимого файла или управление файлами в каталоге: создание, удаление, переименование. w = write
03Выполнение (x)
Запуск файла как программы или вход в каталог. x = execute

Группы владельцев и разрешений

01Пользователь (владелец)
Пользователь, который создал файл. Обозначается u — user.
02Группа
Пользователи, входящие в общую группу, например «developers». Обозначается g — group.
03Остальные
Все остальные пользователи системы. Обозначаются o — others. Это группа, за которой нужно следить в первую очередь.

Команда добавляет разрешения на чтение (r) и запись (w) как для пользователя (u), так и для группы (g), а также отменяет разрешение на выполнение (x) для других пользователей (o) для файла abc.mp4.
КатегорияОперацияРезультат
Пользователь (u)+rwдобавить чтение (r) и запись (w)
Группа (g)+rwдобавить чтение (r) и запись (w)
Другие (o)-xотменить выполнение (x)
02Установка и добавление разрешений
$ chmod ug=rx,o+r abc.c
Предоставляет права на чтение (r) и выполнение (x) как пользователю (u), так и группе (g), а также добавляет право на чтение для других пользователей для файла abc.c.

Virtualization

Oracle VM VirtualBox

Бесплатная виртуализация — больше возможностей

Oracle VM VirtualBox — это бесплатное программное обеспечение для виртуализации, которое позволяет запускать различные операционные системы в виртуальных машинах на одном компьютере. Удобный инструмент для обучения, тестирования и безопасной работы с разными ОС.

01Скачивание
Скачайте установочный файл VirtualBox с официального сайта проекта.
02Установка
Запустите установочный файл и следуйте инструкциям мастера установки.
03Создание виртуальной машины
Задайте имя, тип и версию операционной системы. Выделите объём оперативной памяти и создайте виртуальный жёсткий диск.
04Установка системы
Выберите ISO-образ нужной ОС и запустите виртуальную машину. Следуйте стандартной процедуре установки.
05Использование
Запускайте, останавливайте и управляйте виртуальными машинами через интерфейс VirtualBox.
06Зачем использовать
Обучение и тестирование разных ОС, безопасный запуск подозрительного ПО, разработка и отладка, изолированные рабочие среды.
07Минимальные требования
Windows, macOS или Linux; не менее 2 ГБ ОЗУ; свободное место на диске; аппаратная виртуализация, включённая в BIOS или UEFI.
