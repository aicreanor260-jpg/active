# Лекция «Основы Linux»

`linux.html` — готовая презентация: один самодостаточный файл, открывается в браузере офлайн.
Встроено всё: стили, скрипты, фон и иллюстрации в виде SVG. Внешних зависимостей нет.

- 51 слайд: ядро и дистрибутивы, архитектура и системные вызовы, загрузка, файловая система и пути,
  командная оболочка, потоки и конвейеры, права доступа, пользователи, процессы и сигналы,
  systemd и журналы, пакетные менеджеры, сеть и SSH, диски, архивы, редакторы, bash-скрипты.
- 7 анимированных схем, 2 тренажёра (перевод прав доступа и подбор команды), квиз из 12 вопросов,
  шпаргалка по командам.

## Навигация

| Действие | Клавиши |
| --- | --- |
| Следующий / предыдущий слайд | →, ←, PageUp/PageDown, пробел, колесо мыши, свайп |
| Меню со всеми слайдами | Esc |
| Повторить анимацию слайда | R |
| Перейти к слайду по номеру | набрать номер цифрами |
| В начало / в конец | Home / End |

## Сборка

Разметку генерирует `_linux_build.py` (Python 3, без внешних пакетов):

```
python3 _linux_build.py
```

Скрипт собирает `linux.html` целиком: слайды, сцены анимации, тренажёры. Правки вносятся
в генератор, а не в готовый HTML — иначе они потеряются при следующей сборке.

Движок (CSS, навигация, система сцен) унаследован от деков курса — `decks/_glava9_build.py`
в репозитории `LecturesPart1`, поэтому оформление и управление совпадают с остальными главами.

```html

</a>
```
