# Лекция «Основы Linux»

`linux.html` — готовая презентация: один самодостаточный файл, открывается в браузере офлайн.
Встроено всё: стили, скрипты, фон и иллюстрации в виде SVG. Внешних зависимостей нет.

- 51 слайд: ядро и дистрибутивы, архитектура и системные вызовы, загрузка, файловая система и пути,
  командная оболочка, потоки и конвейеры, права доступа, пользователи, процессы и сигналы,
  systemd и журналы, пакетные менеджеры, сеть и SSH, диски, архивы, редакторы, bash-скрипты.
- 7 анимированных схем, 2 тренажёра (перевод прав доступа и подбор команды), квиз из 12 вопросов,
  шпаргалка по командам.

## Навигация

| Действие | Клавиши |
| --- | --- |
| Следующий / предыдущий слайд | →, ←, PageUp/PageDown, пробел, колесо мыши, свайп |
| Меню со всеми слайдами | Esc |
| Повторить анимацию слайда | R |
| Перейти к слайду по номеру | набрать номер цифрами |
| В начало / в конец | Home / End |

## Сборка

Разметку генерирует `_linux_build.py` (Python 3, без внешних пакетов):

```
python3 _linux_build.py
```

Скрипт собирает `linux.html` целиком: слайды, сцены анимации, тренажёры. Правки вносятся
в генератор, а не в готовый HTML — иначе они потеряются при следующей сборке.

Движок (CSS, навигация, система сцен) унаследован от деков курса — `decks/_glava9_build.py`
в репозитории `LecturesPart1`, поэтому оформление и управление совпадают с остальными главами.

## Чтобы добавить в общий список лекций

Скопируйте `linux.html` в `LecturesPart1/decks/` и добавьте карточку в `decks/index.html`:

<span class="chapter">Лекция</span>
<span class="title">Основы Linux</span>
<span class="meta"><span>51 слайд</span><span class="badge">Тренажёры</span></span>
</a>

# Лекция «Linux: дистрибутивы и работа в терминале»

`linux-basics.html` — второй дек, другой визуальный язык: тёмная графитовая сцена с оранжевым
свечением, перспективная сетка, блоки терминала с раскраской вывода. Один файл, офлайн,
без сборщиков, CDN, внешних шрифтов и картинок.

Содержание построено на материалах лекции (31 инфографика): применение Linux, десять
дистрибутивов, архитектура системы, три уровня файловой системы и её характеристики,
структура каталогов, разбор /etc, /proc, /dev, /usr и журналов, терминал и приглашение,
навигация, `pwd` / `ls` / `cd`, `ls -l`, `touch`, `mkdir` / `rmdir`, `cp`, `mv`, `rm`, `cat`,
`grep`, `sort` и `wc`, `ln`, `locate`, `uname`, права доступа, `chmod` и восьмеричная запись,
VirtualBox. Всего 35 слайдов.

- Команды в терминале набираются посимвольно, вывод появляется целиком после набора,
  курсор перестаёт мигать, когда команда отработала. Повтор — клавишей `R` или щелчком по блоку.
- Интерактив: подбор дистрибутива по трём вопросам, пошаговый разбор строки `ls -l`,
  переключатели битов прав с пересчётом восьмеричной записи, живой терминал с файловой
  системой в памяти, 12 вопросов с разбором.

## Навигация

| Действие | Клавиши |
| --- | --- |
| Следующий / предыдущий шаг | →, ←, пробел |
| Следующий / предыдущий слайд | ↑, ↓, PageUp, PageDown |
| Повторить печать команд | R или щелчок по блоку терминала |
| Содержание сеткой | Esc |
| Переход к слайду по номеру | набрать номер цифрами |

Когда фокус в поле ввода тренажёра, эти клавиши слайдами не управляют: стрелки вверх и вниз
листают историю команд, `Tab` дополняет имена файлов, `Esc` возвращает фокус странице.

## Сборка

```
python3 _linuxbasics_build.py
```

## Что ещё можно заменить

Логотипы дистрибутивов нарисованы условными геометрическими знаками: подлинных исходников
в комплекте нет. Если логотипы понадобятся, их нужно добавить в репозиторий и подставить
в словарь `MARK` генератора.

# Стиль «изумруд и золото» — `network.html`

`network.html` — образец оформления в духе присланных инфографик: глубокий изумрудный фон
с туманом, зерном и виньеткой, тонкие золотые дуги по краям, заголовки антиквой с золотым
градиентом и ореолом, панели со скруглением 16px, золотой рамкой и уголками-засечками.
Один файл, офлайн, без внешних ссылок, шрифтов и картинок — вся графика инлайновый SVG.

3 слайда:

1. «Таблица маршрутизации» — схема R1–R4 с облаками сетей, таблица маршрутизации
   с подсвеченной строкой, пояснение и две карточки (золотая и бирюзовая).
2. «Связь между подсетями» — решётка маршрутизаторов, пунктирные связи, подсвеченный путь
   пакета со стрелками, облака «Сеть N» и «Сеть M», внизу силуэт гор и города со световыми лентами.
3. «Стиль оформления» — палитра, типографика, элементы: панель, акцент, таблица, оборудование.

Талисман курса — енот — стоит на «дороге» второго слайда и выглядывает из-за нижнего края третьего.

Навигация: `→` / `←` / пробел, `Home`, `End`, щелчок по слайду, кнопки в правом нижнем углу.

Палитра: фон `#17664C` → `#010C07`, золото `#EFCF84` / `#FDF0C8` / `#B08C4C`, бирюза `#7CE9D8`,
текст `#F1F8F4` и `#D3E4DC`.
