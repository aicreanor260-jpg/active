# Как передать материалы в Stitch

Главный файл — **STITCH-ALL.md**. В нём уже собраны задание, дизайн, текст обоих PDF, все 29 слайдов PPTX и текстовые расшифровки основных изображений. Скачайте файл и прикрепите его, либо скопируйте его содержимое в чат. Не просите Stitch извлекать текст из страницы GitHub.

Если Markdown не принимается, используйте **STITCH-ALL.txt**: содержимое то же самое. Если сообщение слишком длинное, отправьте файлы `parts/` по порядку; каждый содержит целый раздел без разрыва страницы или слайда. После последней части напишите: «Все материалы переданы, начинай».

Отдельно прикрепите `style-reference.png` — это образец желаемого оформления, а не содержимое лекции.

## Сообщение для Stitch

Создай интерактивную HTML-презентацию «Транспортный уровень» по приложенному STITCH-ALL.md. Внутри есть и учебное содержание, и правила дизайна: читать PDF, PPTX и GitHub не требуется. Изображение style-reference.png показывает желаемый стиль. Нужны адаптивность, стрелки справа внизу, прокрутка переполненного слайда и плавные анимации. Начни с трёх слайдов — обложки, роли транспортного уровня и сравнения TCP/UDP — для проверки оформления. Затем продолжи всю лекцию в том же стиле. Не создавай меню сайта, страницу GitHub или экран авторизации.

## Отдельные исходники в Markdown

- `01-lecture.md`: 17 страниц PDF-лекции.
- `02-handout.md`: 25 страниц второго PDF.
- `03-presentation.md`: 29 слайдов PPTX, включая заметки и ссылки на изображения.
- `04-visuals.md`: таблицы из картинок и описания схем.
- `DESIGN.md`: правила оформления.
- `PROMPT.md`: исходное полное задание в Markdown; для Stitch приоритет имеет задание в начале STITCH-ALL.md, которое не требует читать бинарные источники.
- `images/`: 20 исходных изображений из презентации.

Текст PDF сохранён по страницам. Переносы строк и отдельные подписи могут следовать структуре исходного документа. Таблицы дополнительно преобразованы в Markdown. Подписи из всех растровых скриншотов Wireshark посимвольно не распознавались: их объяснение есть в тексте слайдов. Замеченные расхождения исходников явно отмечены в `04-visuals.md`.
